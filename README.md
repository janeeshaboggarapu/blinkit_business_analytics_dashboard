# Blinkit Business Analytics Dashboard

## About the Project
I created this Power BI dashboard to understand Blinkit's business performance and present the key information in a simple and interactive way.

The dashboard focuses on sales, orders, customers, product categories, delivery status, and payment methods.

## What I Analyzed

- Total Sales
- Total Quantity
- Total Orders
- Average Order Value
- Monthly Sales Trend
- Sales by Category
- Top 5 Categories by Sales
- Delivery Status
- Payment Methods
- Customer Segments

## Tools Used

- Power BI
- DAX
- Power Query
- Data Visualization

## Key Insights

The dashboard makes it easier to see how sales change over time, which categories contribute the most to sales, how customers are segmented, and how orders are delivered and paid for.
